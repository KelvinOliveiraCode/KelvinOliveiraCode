Selecionado em processo seletivo para quatro bootcamps corporativos da DIO (169h no total: Bradesco GenAI 52h, Riachuelo 35h, Santander Excel+IA 29h, CI&T Java AI Copilot 53h), com um projeto publicado em cada um.
