## What I build

Six fronts, one method: deliver the whole project, from raw data to production deploy.

- **Data & AI** — ingestion and modeling pipelines in Python, machine learning models with scikit-learn and XGBoost, dashboards in Streamlit and Excel/Power Query, AI agents with anti-hallucination validation.
- **Java backend** — REST APIs with Spring Boot 3 and Java 21, design patterns applied with purpose, automated tests and a green continuous integration pipeline.
- **Web & Product** — interfaces in React and TypeScript, offline-first PWAs, fast static sites in plain HTML/CSS/JS, and digital products that go from idea to deploy with their own identity.
- **Cybersecurity** — security applied in a lab: pentest scanner with CWE classification, rule-based detection with temporal correlation, MITRE ATT&CK alerts, honeypot, memory forensics and LGPD compliance.
- **Networking & Infrastructure** — LAN topology with VLANs and trunk, Modbus TCP from scratch, Wi-Fi survey by RSSI, copper certification, three-tier VPC, infrastructure as code and cloud cost control.
- **IT & Support** — service desk with queue and SLA by severity, workstation automation with PowerShell in safe mode, backup and restore with hash verification, IP camera onboarding with an audit trail.
